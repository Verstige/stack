## About the Project

Stack is an open-source & self-hostable alternative to Heroku / Netlify / Vercel / etc.

It helps you manage your servers, applications, and databases on your own hardware; you only need an SSH connection. You can manage VPS, Bare Metal, Raspberry PIs, and anything else.

Imagine having the ease of a cloud but with your own servers. That is **Stack**.

No vendor lock-in, which means that all the configurations for your applications/databases/etc are saved to your server. So, if you decide to stop using Stack (oh nooo), you could still manage your running resources. You lose the automations and all the magic. 🪄️

For more information, take a look at our landing page at [stack.io](https://stack.io).

## Installation

```bash
curl -fsSL https://cdn.stack.io/stack/install.sh | bash
```
You can find the installation script source [here](./scripts/install.sh).

> Please refer to the [docs](https://stack.io/docs/installation) for more information about the installation.

## Cloud

If you do not want to self-host Stack, there is a paid cloud version available: [app.stack.io](https://app.stack.io)

For more information & pricing, take a look at our landing page [stack.io](https://stack.io).

## Why should I use the Cloud version?
The recommended way to use Stack is to have one server for Stack and one (or more) for the resources you are deploying. A server is around 4-5$/month.

By subscribing to the cloud version, you get the Stack server for the same price, but with:
- High-availability
- Free email notifications
- Better support
- Less maintenance for you
